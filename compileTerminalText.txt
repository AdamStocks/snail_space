First run this on the Project to compile it:

cargo build --release --target wasm32-unknown-unknown
wasm-bindgen --no-typescript --target web \
    --out-dir ~/Desktop/Snail-Space-Compiles/  \
    --out-name "snail_space" \
    ./target/wasm32-unknown-unknown/release/snail_space.wasm

Then in this window's terminal run this:
wasm-opt -Oz -o snail_space_bg.wasm snail_space_bg.wasm

Then to commit:
git add -A
